# StronaInternetowa
Strona internetowa wykonana w ramach laboratorium aplikacji internetowych
Zawiera:
  - kilka przykładowych podstron
  - interaktywny element navigacyjny
  - szyfrowane logowanie oraz rejestrację
  - panel użytkownika z interaktywną konsolą
Użyte technologie:
  -JQuery
  -Kontenery lokalne
